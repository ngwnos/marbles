# Lebombo

Greg Zaal / Poly Haven, CC0.
https://polyhaven.com/a/lebombo

Original 4K EXR: https://dl.polyhaven.org/file/ph-assets/HDRIs/exr/4k/lebombo_4k.exr
Downloaded 2026-09-12. Stored locally to avoid runtime reliance on external hosting.
Loaded as half-float HDR data; the background uses the original panorama and
material lighting uses a PMREM-filtered copy. No baked exposure or tone mapping.

Background projection uses a flat floor and four vertical walls fitted from
floor/wall junction samples in Poly Haven's 1520×760 panorama preview. Capture
height is estimated at 1.5 m. Wall recesses, stairs, and doorways remain image
detail, so this is an approximate room enclosure rather than a reconstructed
interior. Environment lighting continues to use the unmodified HDR panorama.
