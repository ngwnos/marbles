# Banked U-turn

Reference: [USD305047, top and side drawings](https://patentimages.storage.googleapis.com/f6/21/f8/d6a44e9262fb2d/USD305047.pdf).

The inlet is one standard stacking unit above the outlet. An offset leg descends beyond the outlet, climbs around the far 180-degree bend, then returns beside a narrow divider. The side elevation is continuous across both legs. Dimensions are fitted to the common project port span, not factory measurements.

The shared profile builder now supports integer port elevations and curved floors. Curved floors are refined before warping so cap triangles cannot bridge across the slope. The inlet socket roof conforms to the floor while preserving insertion clearance.
